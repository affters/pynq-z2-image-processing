# FPGA 图像核验证经验包

本目录整理本项目实际产生并验证过的图像核验证经验，入口为
[fpga_image_verification/SKILL.md](fpga_image_verification/SKILL.md)。
该技能可供后续相近任务参考；跨题、跨板和其他团队的复用尚未实测，
目前不把它描述为已经验证的通用 PYNQ 技能。

## 适用范围

- 灰度、3×3 邻域和整帧直方图均衡 RTL 的数值与接口验证。
- `valid/ready` 停顿、反压、帧计数、复位和边界策略检查。
- 对 AXI4-Stream 适配层的 RGB 输入、灰度输出、模式、`TKEEP/TLAST`
  和控制/状态契约进行仿真取证。
- 区分软件参考、RTL 仿真、综合估计、系统实现和实体板卡测试的证据。

## 使用方法

1. 阅读 [SKILL.md](fpga_image_verification/SKILL.md)，先固定颜色顺序、
   算法、位宽、舍入、饱和、图像尺寸、边界和握手规则。
2. 在仓库根目录运行其列出的单核验证入口，确认工具/Python 路径和依赖。
3. 验证当前 AXI4-Stream 适配层时，可运行：

   ```powershell
   & .\scripts\simulate_image_axis.ps1 -Width 128 -Height 96
   ```

4. 同时核对工具退出码、仿真检查、输出数量、独立 Python 逐像素比较和
   `verification.json`，不能只凭日志中的通过字样下结论。
5. 换算法、位宽、尺寸、边界或接口后更新参考并重跑；保存失败日志及首个
   不匹配位置，不能通过改期望结果掩盖实现错误。

## 经验来源和已观察的效果

- `output/gray/verification.json`：选定整数灰度算法的 14,560 点比较通过。
- `output/filters/`：Gaussian、Sobel、锐化、最小窗口及均衡的多帧单核
  仿真结果，具体尺寸、输出数量和适用条件见各结果文件与 SKILL.md。
- `output/axis/axis_128x96/verification.json`：128×96 RGB 输入，五种模式
  输出数量分别为 12,288、11,844、11,844、11,844、12,288；独立逐像素
  比较为 `exact_match=true`，记录明确为 `hardware_test=false`。
- 相关测试台及参考脚本体现了停顿、反压、复位、模式与帧计数检查的做法。
- 独立综合的时序观察促使本技能区分“综合完成”和“约束满足”；LED 实验
  促使本技能区分“JTAG DONE”和“操作系统/SD 启动”。这些经验来自实际
  观察，不构造未经发生的失败历史。

以上结果支持所列项目/向量和接口条件下的验证方法；不自动证明摄像头、
DDR/DMA、网络展示、端到端帧率、功耗或跨题迁移已经通过。系统集成或
硬件验证应引用它们自己的原始报告，不能用此技能替代。

## 失效条件和验证边界

- 颜色顺序、整数公式、位宽、帧尺寸、边界、模式控制或握手变化，会使旧的
  参考与通过结论失效；复用流程前需重新审核契约。
- 当前测试生成器的尺寸/数量上限及工具条件以 SKILL.md 和实际脚本为准；
  RTL 参数可表达某尺寸不代表该尺寸已被验证。
- 计数/像素不匹配、超时、依赖缺失或未解决时序问题必须如实报告。
- 本经验包不授予下载硬件、写 SD/Flash、发布仓库或修改用户设置的权限。
