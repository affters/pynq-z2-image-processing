# v6同步范围与证据说明

本版于2026年11月3日统一256×192实际处理、平面零件尺寸估计、复现入口和匿名技术报告。它是本次报告、代码RAR与源码仓库同步的内容基线；发布提交、容器大小/哈希和公开下载结果由主流程回执另记，不预写已发布或已上传比赛系统。

## 当前内容

- 硬件/固件显式选择256×192，同时保留128×96默认兼容配置；INFO、HWH、ELF和实现清单配对，不能混用。
- 当前PL50MHz、LUT3744、FF4035、BRAM18.5 Tile、DSP0，setup/hold裕量2.962/0.037ns；旧128的6.5 BRAM不再写作当前值。
- 固定图和MF200各10次、486168输出像素exact；GUI独立348帧覆盖五模式、正常Stop，验证循环中位数约0.846fps，非PL延迟。
- 已验证Sobel后的轮廓、ROI、最小外接矩形、两点标定、毫米换算和叠加图均在电脑端完成，原始FPGA数组保持。
- “连接断边”默认开启，关闭时跳过3×3闭运算；14项几何、14项GUI集成及相关旧回归通过。
- 用户确认独立50mm纸面参照线由直尺量得；70.5px对应50mm。标称40×20mm矩形代表读数42.5532×22.6950mm，偏差2.5532/2.6950mm；H实物代表帧估计78.7234×58.8652mm，无独立真实尺寸。

## 复现与材料边界

主入口见[README](../README.md)与[七节技术报告](../report/technical_report.md)。图像输入用`--width 256 --height 192 --baud 2000000`，加载时提供匹配HardwareDirectory；冷启动门禁、失败记录和原始数组保留。尺寸测量需正对、固定的同一平面和已知参照，移动相机/焦距/平面后重新标定；显示两位小数不代表0.01mm精度。

报告PDF/可编辑DOCX为单独交付文件；署名海报、承诺/授权书及身份材料不加入匿名代码树。原297条可见消息匿名快照不扩大，新增工程过程以日期摘要描述，不补造逐字记录。代码包只选定GUI摘要及代表raw，不声称包含全部逐帧数组。包内manifest和selection说明选择与匿名变换，保留源SHA与包副本SHA的区别。

SD/Linux/PYNQ/Jupyter、板端独立USB采集、HDMI、30fps、功耗与CPU/PL独立性能仍未验收。当前测量有毫米级偏差且缺乏独立H真值，不能申报精密计量。完整系统正面/约45°照片、视频、亲签授权书、海报版本复核和比赛上传回执仍需完成。
