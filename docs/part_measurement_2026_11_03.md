# 零件轮廓与尺寸估计功能记录

本地工作版本已在原有五模式图像处理界面中加入轮廓框选、像素长短边测量和两点毫米标定。数据路径是“摄像头接电脑 → RGB发送到开发板 → FPGA计算Sobel边缘 → 电脑逐像素验证 → 电脑提取外轮廓并估计尺寸”。轮廓几何和毫米换算在电脑端完成，不能描述为新增了独立FPGA尺寸测量核。

2026年11月3日已完成数字输入的真实板级验证：两幅固定图分别为矩形和全白对照，FPGA返回的96,520个Sobel像素全部正确，之后的矩形尺寸与空图判断也通过。真实相机的两点标定和毫米显示也已运行。首次用矩形短边标定后，长边读数44.8747mm；后续用用户经直尺量出的独立50mm线标定，矩形读数42.5532×22.6950mm，对标称40×20mm仍有2.5532/2.6950mm偏差。这是实际误差记录，不表示精度验收通过；数字图案验证也不能替代实物精度。

## 已实现的操作

- 勾选“轮廓/尺寸测量（电脑端）”后自动选择Sobel模式，只对实际完成且逐像素一致的Sobel输出做几何计算。
- 对边缘图阈值化，可用“连接断边”开关选择是否作一次3×3闭运算；默认开启，邻近注字被并入轮廓时可关闭。提取ROI内最大的外轮廓，使用最小面积外接矩形给出长边和短边。结果是外包络估计，不是孔径、内轮廓、面积换算或自动零件分类。
- 在右图拖拽设置ROI，减少背景干扰；“全图ROI”可恢复。轮廓碰到ROI或图像边界时报告截断，不输出有效长短边。
- 未标定时仅显示像素。输入实际参照长度，点击“两点标定”，在右图点击两个端点；至少相隔8个实际输出像素才接受，之后才显示毫米估计值。
- 切换离开Sobel会关闭测量，重新开始会清除ROI及标定。相机位置、焦距或测量平面变化后须重新标定。
- 原始FPGA输出、像素校验数组与测量叠加图分别保存。绿色外接矩形和文字属于电脑端叠加，不是FPGA原始返回像素。

## 真实相机测量步骤

现场首次尝试已记录在`output/uart_live/session_20261103_054712_2307f7b6/frame000761_mode2/measurement.json`：用户确认画面固定后，矩形本体只有约58×29个处理像素，浅色线条与紧邻的4cm/2cm注字影响闭合。阈值20、ROI`[52,4,117,38]`、参数版本8返回`truncated`，选中轮廓确实触及ROI顶边；毫米值及标定字段均为空。没有接受无效尺寸，也没有据此修改比例以匹配40mm。已请用户描清矩形、分离注字、扩大并居中后再进行物理标定；实物毫米检查仍待完成。

用户已确认准备一幅长4cm、宽2cm的手画矩形，可将相机调整为尽量垂直朝向桌面。该信息是物理参照的用户说明，尚不是本系统测得的尺寸。

1. 将纸平放，保持相机垂直且固定，让矩形完整处于画面内；用均匀光线减少反光和阴影。参照物与待测物必须处于同一平面。
2. 开始现有256×192演示，勾选“轮廓/尺寸测量（电脑端）”，等待已验证的Sobel边缘。默认阈值40、最小面积80px²，可按实际图像调整。
3. 在右图拖出包含完整矩形及周围空白的ROI，避免纸外背景成为最大轮廓。不要把框压在线条上；若提示截断，应扩大ROI或调整物体位置。
4. 本轮拟用短边作为20mm参照。在“参照长度mm”输入20，点击“两点标定”，选择同一平面中短边的两个对应端点。需要明确所选端点是线条中心还是外缘，后续比较沿用同一定义。
5. 记录标定像素距离、mm/px、长短边像素值及毫米估计值。用未参与标定的长边40mm作为检查值，记录`绝对误差=|测得长边−40|mm`、`相对误差=绝对误差/40×100%`。
6. 保存真实相机输入、原始FPGA输出、`measurement.json`、叠加图和本次最终`result.json`，记录相机姿态、ROI、阈值、标定端点及重复次数。正常Stop后确认没有运行或清理错误。

用短边20mm作标定后，短边接近20mm主要由比例定义决定，不能把它当作独立精度证据。用同一矩形的另一边检查仅证明当前姿态下的一次尺寸估计行为，也不能推导不同距离、不同物体或全画面的测量准确性。

## 误差解释与使用边界

毫米换算为`尺寸mm=外接边跨度px×mm_per_pixel`。一个实际输出像素对应的毫米数由本次标定决定；低分辨率、端点点击误差和边缘位置变化都会影响结果，显示两位小数不表示达到0.01mm精度。

黑色手画线有宽度，Sobel会在线条两侧形成边缘；当前算法测量最大外轮廓的外包络，可能比线条中心之间的长度大数个像素。阈值、模糊、闭运算、角点和光照还会改变外包络位置。应公开端点定义和实测误差，不能把这种系统偏差用四舍五入隐藏。

单一比例不补偿倾斜透视、镜头畸变、物体高度或不同平面。拍摄角度倾斜时，横纵比例也可能不同；若长边检查误差较大，应先调整相机姿态和对焦、检查标定端点与线宽，而不是直接宣称高精度。更严谨的应用需要独立标尺、多位置多尺寸重复检测，或后续实现平面标定/透视校正。

本功能当前为平面外轮廓尺寸估计演示。它没有实现孔径检测、三维尺寸、合格判定、零件分类或量具认证。新源码、报告和证据仍属于本地工作版本；尚未据此更新冻结v5或公开远端，也未因此完成比赛提交。
